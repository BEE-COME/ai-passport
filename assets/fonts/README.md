# Word Learning Notebook fonts

- Source font: Noto Sans CJK SC Regular (OFL), downloaded from
  notofonts/noto-cjk.
- Generated LVGL font sizes: 16 px and 20 px, 4 bpp, uncompressed.
- Regenerate with `python tools/build_fonts.py` after changing UI text or word
  data. The exact character inventory is `font_charset.txt`.
- `lv_font_conv` 1.5.3 via `npx`.
