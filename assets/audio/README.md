# Offline word pronunciation

- `ogden_words.adpcm` is generated by `tools/build_word_audio.py` using
  Piper `en_US-lessac-medium` (MIT-ish neural voice) by default, with eSpeak NG
  1.52.0 (GPL-3.0) as a fallback engine. Output is resampled to 16 kHz mono
  and IMA ADPCM coded.
- The blob is embedded into the application with
  `target_add_binary_data(... RENAME_TO ogden_words_blob)`; index offsets live
  in `main/audio_index.c`.
- Device playback never requires a network. Regeneration records the Piper
  voice/model license and command in this README plus the script arguments.
