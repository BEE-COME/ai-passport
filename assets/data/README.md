# Ogden Basic English 850 data

- Source: <https://ogden.munch.love/>
- Local copy: `ogden-850.json`, generated by `tools/ogden_extract.py`.
- Format: array of 850 records with `w`, `c`, `zh`, `en`, `ex`, `exz`,
  `s`, and `core` fields.
- Status: fetched and validated during this project; the page declares the
  project open source and directly usable. The exact upstream license was not
  separately published on the page at fetch time, so redistribution outside
  this project should re-check the source page before release.
