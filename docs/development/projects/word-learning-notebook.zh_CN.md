# 单词学习本：项目说明

> 状态：V1 已实现；构建、主机测试和设备界面验证已完成。
> 基线：FoloToy AI Passport 仓库 `main`。
> 分支：`feature/word-learning-notebook`。
> 数据源：<https://ogden.munch.love/>（Ogden Basic English 850）。

## 1. 产品概述

单词学习本是一款面向 FoloToy AI Passport 的离线单词学习应用。固件内置
Ogden Basic English 850 的 850 个单词数据与离线发音，开机直接进入中文界面
的学习应用，不使用演示菜单与演示页作为产品外壳。

V1 提供四条主路径：

- 分类浏览：按 6 个分类查阅单词与完整释义。
- 每日学习：按计划顺序逐卡学习，短按确认翻面查看细节，翻面时同步朗读单词。
- 单词自测：中文释义提示、三个英文选项，使用 UP/DOWN 选择、OK 确认，
  作答后朗读正确答案。
- 生词本与统计：收藏生词、查看累计掌握进度，数据断电保留。

## 2. 硬件与 BSP 边界

| 能力 | 本项目的边界 |
| --- | --- |
| 屏幕 | ST7789P3，240×320 竖屏 RGB565，背光由 BSP 控制 |
| 按键 | UP/DOWN/OK 三个 ADC 分压按键，只消费 `BSP_BTN_CLICK` 与 `BSP_BTN_LONG` |
| 扬声器 | ES8311 与 I2S 由 BSP 持有；V1 用于离线朗读单词 |
| 电池 | CW2017 可选；首页右上角显示 SOC，失败时显示占位 |
| 存储 | NVS 24 KB；保持默认分区表，8 MB Flash 足够存放词库与字库 |
| 网络 | V1 不启用 Wi-Fi/BLE；运行时不依赖网络与校时 |

实现只放在 `main`，完全复用 `components/bsp`。除非发现 BSP 缺陷，否则不修改
BSP。程序启动后直接进入单词本应用首页，不再显示硬件演示菜单。

## 3. 功能范围

### 3.1 首页

- 顶部标题为“单词学习本”，右上角显示电池电量。
- 主区显示六项入口：分类浏览、每日学习、单词自测、生词本、学习统计、全部单词。
- 下方显示当前累计进度摘要，例如“已掌握 120 / 850”。

### 3.2 分类浏览

- 分类按数据源固定为：全部 850、操作词 100、通用词 400、图示词 200、
  性质词 100、反义对 50。
- 选择分类后进入单词列表，UP/DOWN 移动，OK 进入单词详情。
- 单词详情展示：单词、中文释义、英文释义、核心意象、例句、例句翻译、
  近义词、分类标签。
- 详情页使用紧凑单屏布局；UP/DOWN 直接切换前后单词，OK 短按朗读当前单词，
  OK 双击收藏/取消收藏，OK 长按返回列表。

### 3.3 每日学习

- 默认每次会话 10 个单词，来源为“全部单词”中按原数据顺序采样；进入
  学习后先展示词面，OK 短按翻面查看全部释义并同步朗读单词；已翻面时
  再按 OK 仅重新朗读。
- UP/DOWN 切换上一词/下一词，翻面即把该词标记为“学习中”。
- 会话结束显示本次已学习数量；进度在会话结束时写入 NVS。

### 3.4 单词自测

- 题目显示中文释义，同时给出三个英文候选词，其中一个正确。
- UP/DOWN 在三个候选之间选择，OK 确认；作答后立即显示对错与正确答案并朗读；
  OK 进入下一题，UP/DOWN 可重听。
- 每题 10 题；答对计入“已掌握”进度，答错默认保留为“学习中”并建议进入
  每日学习复读。
- 会话结束显示正确率，并将结果写入 NVS。

### 3.5 生词本与统计

- 生词本列出已收藏单词，可取消收藏。
- 统计页显示：累计已掌握、学习中、生词数、本次会话学习数。
- V1 不做自然日连续打卡；设备没有可靠时钟源，日历统计放到后续版本。

## 4. 全局交互约定

- 首页：UP/DOWN 短按移动选中项，OK 短按进入，OK 长按无操作。
- 子页面：OK 长按统一返回上一级。
- 列表页：UP/DOWN 短按逐项移动；OK 短按进入详情。
- 详情与卡片：UP/DOWN 前后切换，OK 短按执行当前语境主操作。
- 所有按键回调只入队事件，不直接访问 LVGL；UI 操作由输入任务持锁完成。
- 页面退出前停止可能访问 UI 的任务与定时器，再删除屏幕对象。

## 5. 状态与持久化

- 每个单词保存 2 位状态：未学、学习中、已掌握；850 词约 213 B。
- 每词 1 位收藏标记，约 107 B；加上会话统计，总 NVS 占用远小于 24 KB。
- 用单个 blob 保存词状态，仅在会话结束或明显状态变化时写入，避免频繁
  Flash 写入。
- 若后续加入音频播放，按硬件指南处理 I2S IRAM 安全与并发保存，V1 不引入
  该风险。

## 6. 离线发音

- 发音采用“构建时生成、固件内播放”的方案，设备运行时不访问网络。
- 在构建机上用开源 Piper 神经语音（回退 eSpeak-NG）为 850 个单词逐个合成
  16 kHz 单声道 PCM，再用 IMA ADPCM 压缩后随固件发布。
- 播放时由音频工作任务按块解码并调用 `bsp_audio_set_format(16000,16,1)`
  / `bsp_audio_write` 流式送出；按键回调与 LVGL 任务不参与音频阻塞。
- 850 词压缩后约 2-5 MB Flash，最终以 `idf.py size-components` 实测为准。
- 音频源文件、生成脚本、TTS 与编码工具版本、许可证记录在
  `assets/audio/README.md`，生成的 C 数据由脚本产出并纳入构建。

## 7. 数据与资产

- 从数据站页面内嵌的
  `<script id="data" type="application/json">` 提取 850 条记录。
- 每条字段：`w` 单词、`c` 分类、`zh` 中文释义、`en` 英文释义、
  `ex` 例句、`exz` 例句翻译、`s` 近义词、`core` 核心意象。
- 数据站另有扩展近义词映射，V1 不使用，减少字库和固件体积。
- 数据落地到 `assets/data/ogden-850.json`，生成脚本与转换命令记录在
  `assets/data/README.md`；再次抓取后重新生成并跑覆盖测试。
- 生成静态 C 词表（`main/word_data.c/.h`）放进 Flash 的 `const` 区，
  运行时不做 JSON 解析。
- 当前数据规模：850 条、约 123 KB UTF-8 JSON；页面数据中出现 1623 个
  不同汉字，8 MB Flash 预算内。

## 8. 中文字体与 UI

- 界面主题重新设计为“单词笔记本”：浅色纸面底色、深色墨色正文、分类色
  强调条；不沿用演示的蓝天、草坪、吉祥物与卡片主题。
- 使用开源字体（Noto Sans SC / Source Han Sans 等）按实际文案生成子集：
  固定 UI 文案 + 全部单词数据文案 + 全角标点 + 数字/拉丁字母。
- 至少生成 16 px 与 20 px 两档 LVGL 字体；缺失图标回退 Montserrat。
- 保留 `CONFIG_LV_USE_FONT_PLACEHOLDER=y` 用于开发期检查。
- 增加主机侧字形覆盖测试，遍历实际使用的每个 Unicode 码点，禁止把
  缺失字形当空白隐藏。

## 9. 内存与性能

- ESP32-C3 无 PSRAM；LVGL 池保持 24 KB，屏幕缓冲保持单一 240×20 缓冲。
- 词库与字库以 Flash 只读数据访问，不复制到堆。
- 防止大数组出现在任务栈；列表只渲染可见行，不绘制全部 850 词。
- 实现后运行 `idf.py size-components` 检查 Flash/静态 RAM，并在真机报告
  空闲堆与最大连续块。

## 10. 测试与验收

主机测试：

- 数据完整性与字段约束：850 条、分类数量、无重复单词。
- 音频数据完整性：850 条发音均有数据、长度匹配、ADPCM 解码输出非零。
- 学习/自测状态机：翻面、前后切换、答题判定、进度收敛。
- 字形覆盖：固定文案 + 数据文案的每个码点在所选字体中存在。
- 若生成工具支持，校验生成 C 词表与 JSON 一致。

统一门禁：

- `./tools/validate.sh --static`
- `./tools/validate.sh --firmware`
- 完整 `./tools/validate.sh`（需激活 ESP-IDF 5.5.3）

真机验收项（最终单独报告）：

- 开机直接进入中文首页，无乱码/方框/裁切。
- 三键导航、长按返回、单词切换、翻面、自测选择全部符合预期。
- 电池显示与缺失电量计的降级表现。
- 学习进度在重启后保留。
- 反复进出各页面无崩溃、无内存/任务泄漏。
